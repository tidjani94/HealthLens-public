# HealthLens

HealthLens is a local-first WordPress plugin that tells site owners when something important is wrong and explains what to do next.

## Compatibility

- WordPress 7.0 or newer
- PHP 7.4 or newer
- Multisite: activate per site; network-wide aggregation is not part of the current release

## Support

Use the [public issue tracker](https://github.com/tidjani94/HealthLens-public/issues) for reproducible bugs and usage questions. Do not post credentials, secrets, raw request data, or complete sensitive site exports.
